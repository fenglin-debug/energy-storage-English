# BESS 0.4.0（versionCode 5）

- 点「掌握」不再把词永久移出复习，按间隔重复继续安排。
- 背单词恢复先回忆再看答案；新词仍直接展示完整卡片。
- 点「下一条」之前可以改评价；学习记录只按最后一档写入一次。
- 词汇页恢复搜索、筛选、收藏和词条详情。
- 升级后会自动修复以前因「掌握」被设成永不复习的词，收藏占位不会被当成到期复习。

升级时请直接覆盖安装，不要卸载旧版或清除应用数据。建议升级前先在设置中导出学习记录备份。

# BESS 0.3.1（versionCode 4）

- 文章播放改为由后台 MediaSession 持有真实播放队列，通知栏、锁屏和耳机的上一首/下一首可直接切换文章。
- 新增“自动播放下一篇文章”设置，默认开启；关闭后会在文章边界暂停。
- 普通模式按列表循环，随机模式按本轮随机队列播放，并避免新一轮立即重复当前文章。
- 新增 4 篇 BESS 视频学习文章，包含 4 个离线音频和 251 条中英双语字幕。
- 修复多个内置文章包导入时互相删除的问题，并保留既有文章学习进度。
- 后台每 5 秒以及暂停、切歌、播放完成时保存文章进度。
- 加强学习记录备份的格式、枚举、范围、重复主键及加密参数验证。

升级时请直接覆盖安装，不要卸载旧版或清除应用数据。建议升级前先在设置中导出学习记录备份。
