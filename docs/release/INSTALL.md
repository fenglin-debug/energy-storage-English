# BESS 储能英语训练 App 安装与升级

## 支持设备

- Android 8.0 或更高版本。
- 仅支持 64 位 ARM（arm64-v8a）手机和平板。
- 不支持 32 位设备和 x86/x86_64 模拟器。

## 首次安装

1. 从内部可信渠道取得 `BESS-vX.Y.Z.apk` 和 `SHA256SUMS.txt`。
2. 核对 APK 的 SHA-256；不一致时不要安装。
3. 在 Android 系统提示中，仅为当前文件来源临时允许“安装未知应用”。
4. 打开 APK 完成安装，随后可关闭该来源的安装权限。

## 升级

1. 建议先在“设置 → 学习记录备份”中导出备份。
2. 不要卸载旧版，不要清除应用数据。
3. 直接打开更高版本号的正式 APK，选择“更新”。
4. 更新后检查设置页中的版本号和学习记录数量。

如果系统提示签名不一致、版本过低或安装包无效，请停止操作并联系维护人员；不要通过卸载旧版绕过错误。

应用完全离线，不包含账号、云同步、远程日志或自动更新。每台设备维护独立的学习记录。
